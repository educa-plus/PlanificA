# PlanificA+

Bienvenue sur le dépôt officiel de PlanificA+ !

PlanificA+ est une application de gestion et de planification pédagogique conçue pour simplifier le quotidien du personnel enseignant du primaire et du secondaire. Développée avec le souci constant de remplacer la rigidité des agendas papier traditionnels par un outil numérique flexible et moderne, elle permet aux enseignants de se concentrer sur l'essentiel : la réussite et le bien-être de leurs élèves.  

🌐 Site web officiel : planificaplus.com  

✨ Fonctionnalités clés :
  - Agenda par cycle, ce qui permet aux enseignants d'avoir accès à un horaire fiable qui suit la programmation scolaire.
  - Génération d'un calendrier adapté à votre horaire annuel et suivi de la progression par groupe.
  - Gestion des imprévus : Décalage facile des planifications en un clic lors des journées d'intempéries ou de changements d'horaire.

🌟 Vision & Valeurs
  - 100 % Gratuit & Open Source : Aucune publicité, aucun frais caché et un code source ouvert à la communauté.
  - Accessibilité : Développé pour être rapide et intuitif.
  - Esprit collectif : Un outil conçu pour faciliter l'entraide, particulièrement pour les nouveaux arrivants dans la profession enseignante.
